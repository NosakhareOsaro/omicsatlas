# OmicsAtlas

A multi-modal explorer unifying single-cell RNA-seq, spatial transcriptomics, ATAC-seq,
and bulk RNA-seq analysis of human breast cancer, built around a novel statistically
grounded metric for scoring cross-modality cell-type concordance.
